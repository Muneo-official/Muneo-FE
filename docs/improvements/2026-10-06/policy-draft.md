## 적용한 화면

- `/privacy`: 처리 목적·정보 항목·보관·외부 처리·삭제·권리 행사·쿠키·안전조치·변경 안내 초안.
- `/terms`: 운영자·서비스 범위·계정·AI 결과 한계·업로드 권한·금지 행위·중단·탈퇴·책임·변경 안내 초안.
- 두 문서는 로그인 없이 접근 가능하다. 목차 이동, 문서 전환, 운영자 이메일 링크를 제공한다.
- 랜딩 푸터의 기존 `#` 링크를 실제 문서 경로로 연결하고 운영자·문의 이메일을 표시했다.
- 이메일 가입과 카카오 추가 가입 화면에서 새 탭으로 열어 작성 중인 입력값을 유지한다.
- 초안 배지와 시행일 미정, 항목별 ‘운영 확인 필요’를 명시했다. 검색 노출은 `noindex`로 설정하고 사이트맵에는 추가하지 않았다.
- 최종 약관 동의 체크박스나 동의 간주 문구는 추가하지 않았다. 문서 확정 후 동의 API와 함께 연결할 작업이다.

본문 원본은 `apps/web/src/app/(legal)/_content/privacy.ts`, `terms.ts`에 있다. 이 문서는 적용 기록이며 본문의 별도 사본을 유지하지 않는다.

단순히 초안 표시를 지우면 최종 문서가 되는 것은 아니다. 위 값을 실제 동작과 대조해 확정한 뒤 본문·버전·시행일과 필요한 가입 동의 기록을 반영한다. 현재 코드는 수정했으며 배포는 실행하지 않았다.

## 검증

- 웹 타입 검사, 변경 코드 린트, 프로덕션 빌드 통과.
- 익명 접근, 초안·운영자·문의 이메일·검색 제외 메타데이터 확인.
- 320px·390px·1280px에서 가로 넘침 없음, 모바일·데스크톱 화면 확인.
- 가입 화면에서 정책을 새 탭으로 열어도 이메일 입력값 유지.
- 카카오 추가 가입 화면과 랜딩 푸터의 두 정책 링크 확인.
- 브라우저 검사 중 페이지 실행 오류 없음. 실제 회원가입 제출이나 외부 메일 발송은 하지 않았다.

## 작성 기준

처리 목적·보유 기간·외부 처리·파기·권리 행사·문의처를 빠짐없이 검토할 수 있도록 구성했다. [개인정보 보호법 제30조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1032645945)의 항목을 참고하되 실제 운영이 미확정인 부분은 확정 사실로 쓰지 않았다.

읽기 쉬운 한국어 조항과 중요한 내용의 구분은 [약관법 제3조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1029708921)를 참고했다. AI 결과의 한계를 안내하면서 운영자 책임을 전면 배제하는 문구는 넣지 않았다. [약관법 제6조·제7조](https://law.go.kr/LSW/lsEfInfoP.do?lsiSeq=253655)의 일반 원칙·면책 조항을 대조했다.
