```bash
git show --stat 3a84c53
git show 3d7e870
git log --reverse --oneline 52b8490..HEAD
```

피드백 화면은 앞선 API 커밋에 의존한다. 어드민 QA는 앞선 오류 안내 변경과 함께 사용한다.

## 검증과 푸시 범위

- 구현 후 완료한 검사: 웹 199개·어드민 53개 테스트, 웹 주요 브라우저 흐름 7개·어드민 2개, 타입 검사·린트·두 앱의 프로덕션 빌드.
- 커밋 시 기존 Husky/lint-staged 검사를 실행했다. 코드·설정 17개 파일의 SHA-256을 분리 전후 대조해 검증 당시 내용이 보존되었음을 확인했다.
- 실제 ADMIN 계정으로 로그인한 뒤 DB 저장 기록을 대조하는 검증은 남아 있다. 테스트 결과의 데이터는 로컬 mock이며, 공개 OpenAPI 경로 확인과 실제 데이터 조회 성공을 구분한다.
- 푸시 대상은 현재 `main`의 기존 15개 + 이번 6개, 총 21개 커밋이다. 다른 로컬 브랜치나 태그는 이번 대상에 포함하지 않는다.
- `main`에 푸시하면 저장소 설정에 따라 `Deploy Production` 워크플로가 실행된다. Git 푸시 성공과 운영 배포 성공은 별도 상태다.

실제 확인 절차는 [연동 및 합동 QA](./backend-integration.md), 어드민 기능 설명은 [어드민 작업 내역](./admin-work-summary.md)를 참고한다.
